## Key Integration Points

```
1??  Stock.DailyStockPricesGiven EVENT
    ?? Triggered by: Data provider
    ?? Payload: DailyStockPricesEventArgs
    ?? Contains: StockBar[] with OHLCV data

2??  AnalysisVM.OnDailyStockPricesGiven() HANDLER
    ?? Receives: Event with all bars
    ?? Stores: In _allBars
    ?? Filters: By current interval
    ?? Updates: FilteredBars property

3??  Analysis.xaml BINDINGS
    ?? ComboBox: ItemsSource = AvailableIntervals
    ?? ComboBox: SelectedItem = SelectedInterval
    ?? Chart: Series = CandleSeriesCollection
    ?? Converter: IntervalToStringConverter
```
